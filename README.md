# gallowforge.github.io

The source of [gallowforge.github.io](https://gallowforge.github.io): one page, written by hand, about what I build and how I work.

What is here is what the browser gets, unminified and readable:

- `index.html`: the page: capabilities, method, measurements, toolkit, background and contact
- `assets/style.css`: the styles, dark and light
- `assets/main.js`: the theme switch, the copy button, the stack in the first view and the section marker
- `assets/Ali-Husain-CV.pdf` and `assets/Ali-Husain-CV-plain.pdf`: the CV, designed and plain
- `work/` and `ledger/`: old addresses, kept so that links to them land on the home page
- `404.html`: the page for an address that does not exist

There is no framework and no tracker, and the page sets no cookie. The only thing it keeps is the theme you chose, on your own device.
