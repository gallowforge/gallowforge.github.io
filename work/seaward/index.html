03 Infrastructure/Seaward

Seaward

Command-line tool · open source

Which ports on a Linux server can really be reached from outside, and the rule that decides each one.

A firewall's list is what was asked for; the rules the kernel runs are what the server got. Docker publishes a port with rules of its own, and a database answers the whole internet while ufw still reads deny. Seaward reads the rules that are really loaded, follows a packet through them the way the kernel does, and says for every port who can reach it and which rule decides. It only reads: it changes no rule and puts no packet on the network.
